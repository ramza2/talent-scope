# 10. Information Architecture

## 1. IA 원칙

1차 MVP의 메뉴와 화면 구조는 실제 업무 흐름인 `문서등록 → AI 분석검토 → 인력 프로필 → 검색`이 자연스럽게 이어지도록 구성한다.

문서, 프로젝트, 학력/자격은 별도 메인 메뉴로 분리하지 않고 인력 상세의 하위 데이터로 관리한다.

## 2. 전체 메뉴 구조

```text
로그인
  │
  └─ 메인 시스템
      ├─ 1. 대시보드
      │
      ├─ 2. 인력관리
      │    ├─ 인력 목록
      │    ├─ 신규 인력 등록
      │    └─ AI 분석 검토
      │
      ├─ 3. 인력검색
      │    └─ 통합 인력검색
      │
      └─ 4. 관리
           ├─ 코드 관리
           ├─ 사용자 관리
           └─ AI 분석 현황
```

## 3. 로그인

기능:
- ID/Password 로그인
- 로그인 실패 안내
- 비활성 사용자 차단

MVP에서는 SSO/LDAP/2FA를 지원하지 않는다.

## 4. 공통 Layout

```text
┌─────────────────────────────────────────────────────────┐
│ TalentScope              [빠른 이름검색]       사용자  │
├──────────────┬──────────────────────────────────────────┤
│ 대시보드     │                                          │
│              │                                          │
│ 인력관리     │              Main Content                │
│ - 인력 목록  │                                          │
│ - 신규 등록  │                                          │
│ - AI 검토    │                                          │
│              │                                          │
│ 인력검색     │                                          │
│              │                                          │
│ 관리         │                                          │
└──────────────┴──────────────────────────────────────────┘
```

상단 빠른 검색은 이름 중심으로 인력 상세에 빠르게 접근하는 용도이며 복잡한 AI 검색은 통합 인력검색 화면에서 수행한다.

## 5. 대시보드

대시보드는 통계보다 처리해야 할 업무 Queue 중심으로 구성한다.

주요 카드:
- 전체 인력 수
- 최근 30일 등록 인력
- AI 검토 대기 건수
- AI 분석 실패 건수

하위 영역:
- 최근 등록 인력
- 검토 대기 문서
- 분석 실패/재처리 필요 문서

## 6. 인력관리 > 인력 목록

목적: 전체 인력을 조회하고 관리 대상 인력의 상세화면으로 이동한다.

주요 컬럼:
- 이름
- 주 직무
- 기술등급
- 총 경력
- 주요기술
- 주요 전문분야
- 소속
- 최종 갱신일
- 문서/분석 상태

간단 Filter:
- 이름
- 직무
- 등급
- 기술
- 소속
- 상태

복잡한 추천/의미검색은 이 화면이 아니라 통합 인력검색에서 수행한다.

## 7. 인력관리 > 신규 인력 등록

문서 중심 등록 Flow:

```text
파일 Drag & Drop / 파일선택
  → 문서종류 지정
  → 업로드
  → AI 기본 식별정보 분석
  → 기존 인력 중복 확인
  → 신규 인력 생성 또는 기존 인력 연결
  → 상세 분석 시작
```

다중 파일 업로드를 지원하고 파일별 문서종류를 사용자가 수정할 수 있다.

## 8. 인력관리 > AI 분석 검토

관리자용 Queue 화면.

상태 탭 예:
- 검토대기
- 분석중
- 실패
- 완료

목록 항목:
- 인력
- 문서명/종류
- 신규/변경/충돌 건수
- 분석상태
- 분석일
- 검토 버튼
- 실패 시 재분석 버튼

## 9. AI 분석 결과 검토 화면

문서 단위 Candidate Profile과 기존 Confirmed Profile을 비교한다.

섹션:
- 요약: NEW / UPDATE / CONFLICT 건수
- 기본정보
- 직무·기술
- 전문분야
- 프로젝트
- 학력·자격

각 항목에서:
- 기존값
- 신규 추출값
- 원문 근거
- Confidence
- 적용/유지/수정 선택

하단:
- 임시저장
- 확정 및 DB 반영

## 10. 인력 상세

상단 Summary:
- 이름
- 기술등급
- 주 직무/부 직무
- 총 경력
- 소속
- 연락처/이메일
- 주요기술
- 전문분야
- 최근 갱신일
- 프로필 수정 / 문서 추가

하위 탭:

```text
[프로필]
[직무·기술]
[프로젝트 경력]
[학력·자격]
[문서]
[변경이력]
```

### 프로필 탭
기본정보, 경력, AI/확정 요약, 전문성 Summary를 표시한다.

### 직무·기술 탭
주/부/경험 직무와 기술별 최근 사용년도, 근거 프로젝트를 표시한다.

### 프로젝트 경력 탭
기간 역순으로 프로젝트를 표시하고 역할/기술/사업분야 필터를 제공한다.

### 학력·자격 탭
학력과 자격증/인증 정보를 표시한다.

### 문서 탭
문서종류별 최신/과거 버전을 표시하고 미리보기/다운로드/버전보기를 제공한다.

### 변경이력 탭
문서 등록, AI 반영, 직접 수정 등의 인력 단위 Timeline을 표시한다.

## 11. 인력검색 > 통합 인력검색

자연어검색과 조건검색을 한 화면에서 연결한다.

상단:

```text
[ AI 개발 경험 있고 RAG 해본 특급 인력 찾아줘 ] [AI 검색]
```

AI 해석 결과:

```text
필수: AI개발자, 특급
선호: RAG
의미검색: LLM/RAG 기반 AI 시스템 구축 경험
[조건 수정]
```

선택식 조건:
- 직무
- 등급
- 경력
- 기술
- 전문분야
- 상세조건: 사업분야, 고객유형, 소속, 자격증, 프로젝트 키워드 등

AI가 해석한 조건은 선택식 UI에 자동 반영되고 사용자가 변경할 수 있다.

## 12. 통합검색 결과

결과 카드 주요정보:
- 적합도 점수
- 이름
- 등급/주 직무/총 경력
- 주요기술
- 조건 충족표
- 주요 관련 프로젝트
- 상세 프로필
- 검색근거 보기

`검색근거 보기`는 Drawer/Modal 형태로 프로젝트 및 원본문서 Evidence를 표시한다.

## 13. 0건 검색

0건인 경우 필수조건을 자동으로 완화하지 않고 가능한 완화안을 제시한다.

예:
- 특정 사업분야 제외 시 3명
- 등급을 고급 이상으로 변경 시 7명

사용자가 선택한 경우에만 검색조건을 변경한다.

## 14. 관리 > 코드 관리

하나의 화면에서 탭으로 관리한다.

- JOB 직무
- TECH 기술
- EXP 전문분야
- BIZ 사업분야
- CUSTOMER_TYPE 고객유형
- 문서종류

관리 항목:
- 코드
- 표준명
- 상위코드
- Alias
- 활성여부

## 15. 관리 > 사용자 관리

목록:
- 사용자명/ID
- 역할
- 상태
- 최근 로그인

기능:
- 사용자 생성/수정
- 일반사용자/관리자 변경
- 활성/비활성
- 비밀번호 초기화

## 16. 관리 > AI 분석 현황

운영/장애 확인 화면.

표시:
- 오늘 분석 건수
- 완료/처리중/실패 건수
- 최근 실패 문서
- 실패사유
- 재처리

## 17. 전체 화면 Flow

```text
로그인
  → 대시보드
     ├→ 신규 인력등록
     │   → 문서 업로드
     │   → AI 문서분석
     │   → 분석 검토
     │   → 사용자 확정
     │   → 인력 상세 / Profile DB / Embedding
     │
     └→ 통합 인력검색
         → 자연어/조건 분석
         → Hybrid Search
         → 검색결과
         → 추천근거
         → 인력 상세
```

## 18. 메뉴별 접근권한

| 1Depth | 2Depth | 일반사용자 | 관리자 |
|---|---|---:|---:|
| 대시보드 | - | O | O |
| 인력관리 | 인력 목록 | O | O |
| 인력관리 | 신규 인력 등록 | X | O |
| 인력관리 | AI 분석 검토 | X | O |
| 인력검색 | 통합 인력검색 | O | O |
| 관리 | 코드 관리 | X | O |
| 관리 | 사용자 관리 | X | O |
| 관리 | AI 분석 현황 | X | O |
